Bellow

Free, private dictation for your Mac. Press ⌃⌥X, speak, press it again, and clean English text is typed into whatever app you are using.

Everything runs on your Mac. No account, no API key, no network access after the one-time model download, and no transcripts leave the machine. Whisper transcribes, a local language model tidies up the wording, and the result is typed for you.

Latest release: see GitHub

Install

The app is a small download. It fetches its speech and cleanup models (2 to 3.4 GB, once) the first time you start it.

Download Bellow for Apple Silicon

  1. Open the downloaded .dmg and drag Bellow into Applications.
  2. Open Bellow from Applications. It is signed and notarized by Apple, so it opens without a security warning.
  3. In the setup window, allow Microphone and Accessibility when macOS asks, and click Start.
  4. Wait for the status to read Ready while the models download. If the download is interrupted, click Start again and it resumes.
  5. Click into any text field, press ⌃⌥X, talk, and press it again.
  6. That is all. Bellow checks for updates once a day and asks before installing one.

Prefer the terminal?

This one line downloads the app, verifies its checksum, puts it in Applications, and opens it:

curl -fsSL https://xuancongwen.github.io/bellow-app/install.sh | bash

You can read the script first. To check a manual download instead, get the .dmg.sha256 file next to the DMG on the releases page and run:

cd ~/Downloads
shasum -a 256 -c Bellow-1.0.0-rc.14-macOS-arm64.dmg.sha256

Requirements

MacApple Silicon (M1 or newer). Intel Macs are not supported.
macOS13.3 Ventura or newer
Memory8 GB minimum. Macs with 24 GB or more get the larger Max cleanup model; the app will not load its models below 8 GB.
DiskAbout 6 GB free for the models the app downloads on first start

Using it

  • Recording is a toggle: press ⌃⌥X to start and again to stop. Recordings stop on their own at two minutes.
  • Stay in the same window while the text is being typed.
  • Quit from the menu bar icon when you want the memory back.

Uninstall

Quit Bellow, drag it from Applications to the Trash, and delete ~/Library/Application Support/Bellow to remove the models.
